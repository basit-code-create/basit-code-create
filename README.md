
## Services
- **User Authentication:** Secure signup/login using JWT & bcrypt.
- **RESTful API:** Clean API structure powered by Node.js and Express.
- **Database Architecture:** MongoDB with Mongoose schemas and relationships.
- **Responsive UI:** Modern, mobile-first design built with React and Tailwind CSS / Material UI.
- **State Management:** Managed via Redux Toolkit / Context API.
| **Frontend** | React, React Router, Redux Toolkit, Tailwind CSS / Axios |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB, Mongoose |
| **Auth & Security** | JSON Web Tokens (JWT), bcryptjs, CORS, dotenv |
